# ⚖️ Direitos Civis — Landing Page

Landing page desenvolvida como trabalho para o curso de **Administração — Jovem Aprendiz**, abordando o tema **Direitos Civis**: o que são, onde e como surgiram e em qual contexto histórico se consolidaram.

## 💡 Sobre o projeto

Este projeto nasceu a partir de uma atividade do curso de Administração do programa Jovem Aprendiz. A proposta era apresentar um conteúdo sobre direitos civis de forma clara e acessível — e eu decidi ir além do convencional: em vez de uma apresentação tradicional, construí uma **landing page completa do zero**, colocando em prática e aperfeiçoando minhas habilidades em desenvolvimento web.

## 🚀 O que eu aprendi e pratiquei

- **HTML** — Estruturação semântica de conteúdo, uso de tags como `<section>`, `<header>`, `<footer>`, `<blockquote>` e boas práticas de acessibilidade.
- **CSS** — Design responsivo, tipografia com Google Fonts, animações com `@keyframes`, gradientes, pseudo-elementos e layout com Flexbox.
- **JavaScript** — Manipulação do DOM com `Intersection Observer API` para criar animações de fade-in ao rolar a página.

## 🎨 Design

A página segue um conceito visual **minimalista em preto e branco**, transmitindo seriedade e elegância ao tema. Destaques do design:

- Tipografia serifada (*Cormorant Garamond*) para títulos e citações
- Tipografia sans-serif (*Inter*) para corpo de texto
- Animações suaves de entrada ao rolar
- Layout totalmente responsivo (desktop e mobile)

## 📁 Estrutura do projeto

```
landing-direitos-civis/
├── index.html   → Estrutura e conteúdo da página
├── style.css    → Estilos visuais e responsividade

```
